# Происхождение ресурсов

Графика первого этапа создаётся программно в lib/game/highway_art.dart: дорога, горы, съезды, растительность, силуэты бойцов и зомби. Сторонние изображения, музыка и шрифты не скачиваются. Используются стандартные шрифты и Material icons Flutter.

Flutter распространяется по BSD-3-Clause, Flame — MIT. Их уведомления входят в сборку через механизм лицензий Flutter. Пакеты фиксируются pubspec.lock после разрешения зависимостей; CI прикладывает использованный lockfile к результатам. Лицензия собственного кода проекта пока не выбрана.

Нет материалов Last War, Last Z или других референсов. Нет SDK аналитики, рекламы или удалённых ресурсов игры.
