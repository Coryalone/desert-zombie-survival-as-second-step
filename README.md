# Desert Zombie Survival

Рабочее название. Одиночный офлайн-шутер про отряд на пустынной автостраде.

## Статус

Согласование требований. Игровой код и сборки пока отсутствуют; движок ещё не выбран. Этот репозиторий независим от Waha-match3.

[Требования v0.1](docs/requirements-v0.1.md)

## Платформы

- Android — основная платформа, управление пальцем.
- Web на ПК — тестирование в браузере, управление мышью.
- Горизонтальный экран на обеих платформах.
- iOS и TestFlight не входят в текущий объём.

## Концепция

Отряд перемещается влево-вправо и отбивается от волн зомби на автостраде с боковыми съездами. Ограниченное время стрельбы приходится распределять между врагами и разрушаемыми контейнерами с бойцами, оружием и техникой. Для теста предусмотрены пять уровней с целью выжить две минуты.

## Этапы

1. Выбор движка, минимальная структура проекта и проверка Web/Android-сборки.
2. Управление, стрельба, один тип врага, столкновения и поражение.
3. Бонус +1 и выбор между бонусом и врагами.
4. Второй обычный враг, боковые съезды, элитка и босс.
5. Оружие, техника, пять уровней и согласованное сохранение.
6. Графика, звук, производительность, проверка APK и лицензий.

После каждого этапа — проверка его сценариев. Изменения выполняются небольшими порциями; успешный запуск в браузере не заменяет тест на Android.

## Приватность и материалы

Без рекламы, аккаунтов, платежей, аналитики и сбора персональных данных. Ресурсы упакованы в приложение. Android release без INTERNET и ненужных разрешений; сохранения только в private app storage, backup отключён. Эти требования должны проверяться на готовом APK.

Для стороннего кода, графики, шрифтов и аудио сохраняются источники и лицензии. Лицензия самого проекта пока не выбрана. Секреты и ключи для офлайн-прототипа не нужны.
