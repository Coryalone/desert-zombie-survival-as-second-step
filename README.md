# Desert Highway

Первый прототип зомби-шутера на Flutter + Flame для Android и браузера ПК. Горизонтальный экран, 2D с перспективой.

## Первый запуск

Склонировать репозиторий в папку без кириллицы. В корне запустить **Run-Web.cmd**. Он подготовит платформы через уже установленный Flutter, установит зависимости и откроет Chrome.

**Build-APK.cmd** запускает анализ, тесты и Android release-сборку. APK появится в build/app/outputs/flutter-apk/app-release.apk.

## Сейчас

Один тестовый двухминутный бой: три бойца, обычные зомби, автострельба, движение пальцем/мышью и A/D, HP и потери, пауза, победа/поражение, повтор.

Следом: бонус +1 и выбор целей. Боссы, техника, сохранения, аудио и пять уровней ещё не реализованы.

## Приватность

Без аккаунтов, аналитики, рекламы и удалённого контента игры. Подготовка проекта и установка SDK/пакетов требуют сети; установленная Android-игра — нет. Доступ к интернету и данным телефона не запрашивается, backup отключён. AndroidX добавляет только внутреннее разрешение DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION с защитой signature; это не доступ к пользовательским данным. CI дополнительно проверяет разрешения готового APK. Проверка поведения на реальном телефоне остаётся обязательной.

Проект независим от Waha-match3. iOS пока вне объёма. Движок выбран: Flutter + Flame, без Godot.
